# 文型道場 第2試作版

名詞・動詞・形容詞のカードを `S / V / O/C / O₂/C` の4スロットへドラッグし、英文を完成させる一人用ブラウザゲームです。

## 起動方法

`index.html` をブラウザで開くだけで遊べます。外部ライブラリ、通信、アカウントは不要です。

ローカルサーバーで開く場合は、このフォルダーで次を実行します。

```sh
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 現在入っている機能

- 人間1人＋CPU 1〜3人
- CPUレベルはノーマル／ハードから選択
- SV / SVC / SVO / SVOO / SVOC
- カード配分は名詞50枚・形容詞20枚・動詞27枚（動詞は各文型を主役に5〜6枚ずつ）
- マウス・タッチ両対応のドラッグ＆ドロップ（クリック操作も可能）
- 場の表示は常に `S / V / O/C / O₂/C` のまま固定し、正解の役割を先に見せない設計
- 手札では動詞の原形を表示し、場では主語に合わせて現在形へ変化
- 同じ存在がSとOに置かれた場合の再帰代名詞への自動変化
- I / me / myself などの代名詞の格変化
- 合法手だけを選ぶルール型CPU
- CPUの手札をカード裏面だけで表示し、カードを出す・引く動きをアニメーション化
- CPUの手札は通常1枚ずつ離して表示し、8枚以上から少しずつ重ねる
- 手番のプレイヤー枠と上部表示を、あなたは緑・CPUは赤系で強調
- ハードCPUはノーマルCPUより少し速いテンポでカードを出す
- 山札のボタンはプレイヤーの手元に配置し、引くカードは画面右側からアニメーション表示
- 山札から引いたカードは自動選択せず、手札へ加えるだけ
- 出せないときは山札から1枚だけ引き、そのカードも出せなければパス
- 山札も捨て札も空で、手札から出せるカードがない場合は自動でパス
- 出せない場所へのカード配置は「おてつき」となり、1枚引いて手番終了
- おてつき時は場の区画だけに「おてつき！ 一枚引く」のカットインを表示
- 合法手の強調やヒントを出さず、自分で文型を判断するプレイ方式
- 残っている全員が連続でパスしたときだけ、場のカードを流して仕切り直す
- 全員パスによる場流し時は専用ポップアップで通知
- 上部の「スタート画面へ」から人数・CPUレベル選択へ戻れる
- 白樺の道場を思わせるライトモードと、黒檀調のダークモード
- 白樺・和紙の軽量なローカル画像素材とLucide公式アイコンを同梱
- 典型的なデスクトップ画面では、手番・相手・場・手札を一画面で確認できる高密度レイアウト
- 完成時に英文・和訳・第何文型かを表示し、ゲーム終了時に全文をリザルトへ掲載
- 順位、速さ、CPUレベル・人数、終了時のCPU全員の手札平均、おてつき回数からスコアを算出。速さは判断時間の合計を3割、1手番平均を10手番相当に換算した時間を7割で評価（自動パスは回数から除外）。CPUが2人・3人なら300点加算、CPUの残り札平均（切り捨て）×50点を加算、おてつきは1回500点減点
- スコアに応じて「文型師範」「文型師匠」「文型弟子」「文型見習い」の称号を表示
- 「文型師範」は14,200点以上。「文型見習い」には下限なし
- 対戦終了時にふすまが閉じ、「そこまで！」を表示してからリザルトへ移行
- 対戦開始時は「いざ尋常に…」から「参る！」へ切り替わるカットインを表示
- 音は毎回OFFで開始。右上のボタンでONにすると、スタート画面と対戦中のBGMがそれぞれループ再生される
- 開始・完成・おてつき・終了・称号表示・ボタン操作に効果音を付ける
- 名詞は「S・O・Cになる」、形容詞は「Cになる」、動詞は「取れる文型」と表示
- 「遊び方」の「その他」で、収録動詞27語と各動詞が取れる文型の一覧を公開
- 上がり順位
- スマートフォンでは上部表示を圧縮し、手札を小型カードの二段表示に変更
- リザルトから「もう一度遊ぶ」と「スタート画面へ」を選択可能
